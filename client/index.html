One click from the desktop into the rift.

Rift Client is the Rift Events Minecraft client. Hit Play in Rift Events mode and it starts the game and drops you straight onto riftevents.net, or sends the game you already have open. It comes with a built-in HUD and a Right Shift mod menu, and it updates itself.

Download for Windows

Latest release on GitHub

What you get

Built for Rift Events

Rift Events mode

Click the RE logo in the launcher, press Play, and you're on the server. Already in game? It asks whether to join for you or open a new window.

⌨

Right Shift menu

Press RIGHT SHIFT in game to drag your HUD around, resize it, and switch any mod on or off.

📈

46 built-in mods

FPS, CPS, keystrokes, armor, potions, zoom, toggle sprint, custom crosshair and more. No mods folder, nothing to install yourself.

🔄

Updates itself

New versions download in the background and install the next time you restart the launcher.

Getting started

Install in a minute

  1. Download the installerUse the button above. It's one file, about 100 MB.
  2. Run itIf Windows says "Windows protected your PC", click More info → Run anyway. That happens with new apps that aren't code-signed yet.
  3. Sign in with MicrosoftUse the account that owns Minecraft: Java Edition. Your password goes to Microsoft's own sign-in page, never to us.
  4. Click RE, then PlayThe first launch downloads Minecraft and Java (a few minutes). After that you're straight in.
